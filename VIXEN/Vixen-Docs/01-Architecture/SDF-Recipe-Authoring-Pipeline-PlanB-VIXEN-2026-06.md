# Recipe Authoring → Render — Plan B (VIXEN: Registry, Bake-to-Pool, Render Binding) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make VIXEN ingest arbitrary pre-compiled SDF recipes, register them under stable U32 ids, bake each into a Stored octree in a memory-budgeted (count-unbounded) pool, and render them through the shipped ESVO instanced path.

**Architecture:** A new engine-owned `RecipeRegistry` (`U32 → {bytecode, bakeParams, octreeSlot}`) is populated from a pack manifest. Each registered recipe is voxelized via the existing `BakeRecipeInstructionsToSdfWorld` + `BuildSdfBodyOctree`, concatenated into a generalized octree pool (the hardcoded 3-octree cap is lifted; per-octree `OctreeConfig` moves from a fixed UBO to a runtime-sized SSBO), and drawn as `providerKind=Stored, octreeIndex=slot` — the render path is unchanged.

**Tech Stack:** C++23, Vulkan 1.3, GLSL compute, CMake (Ninja), GoogleTest, lavapipe (software Vulkan) for headless render gates.

## Shared interface (the container/reader contract — Plan A produces, Plan B consumes)

The blob is **one recipe**: a fixed header + the `SdfInstruction[]` stream. The pack manifest maps `namespaced-id → U32 recipeId → blob`. The generated reader (Plan A) exposes, in `Recipe/generated/RecipeContainer.g.h`:

```cpp
namespace Yeroket::Sdf::Generated {
// Little-endian, blittable. Mirrors the canonical C# container writer.
struct RecipeContainerHeader {
    uint32_t magic;            // 'VRC1' = 0x31435256
    uint32_t formatVersion;    // bumped on any layout change
    uint32_t instructionCount; // number of SdfInstruction records that follow
    uint32_t bakeResolution;   // grid side n (e.g. 64); 0 = use engine default
    float    bandVoxels;       // narrow-band radius in voxels (e.g. 2.5); 0 = default
    uint32_t brickDepth;       // 3 = 8^3 bricks; 0 = default (3)
    uint32_t reserved[2];      // forward-compat; writer zeroes
};
// View over an in-memory blob (no copy). instructions points into `blob`.
struct RecipeContainerView {
    RecipeContainerHeader header;
    const SdfInstruction* instructions; // count = header.instructionCount
};
// Returns false (and leaves `out` untouched) on: bad magic, version mismatch,
// or len inconsistent with sizeof(header)+count*sizeof(SdfInstruction).
bool ReadRecipeContainer(const uint8_t* blob, size_t len, RecipeContainerView& out);
} // namespace
```

`SdfInstruction` is also promoted to a generated struct in Plan A (same 132-byte layout); VIXEN's hand-written `libraries/SVO/include/Recipe/SdfInstruction.h` is replaced by an include of the vendored generated header in Plan A's final step. Until then, Plan-B tasks use the existing `Vixen::SVO::Recipe::SdfInstruction`.

```cpp
// libraries/SVO/include/Recipe/RecipeRegistry.h
#pragma once
#include <cstdint>
#include <map>
#include <vector>
#include "Recipe/SdfInstruction.h"
#include "generated/SdfOpCodes.g.h"   // codegen enum; valid-opcode set

namespace Vixen::SVO {

class RecipeRegistry {
public:
    static constexpr uint32_t kUnbakedSlot = 0xFFFFFFFFu;

    struct RecipeEntry {
        std::vector<Recipe::SdfInstruction> bytecode;
        uint32_t bakeResolution = 0;   // 0 = engine default
        float    bandVoxels     = 0.f; // 0 = engine default
        uint32_t brickDepth     = 0;   // 0 = engine default (3)
        uint32_t octreeSlot     = kUnbakedSlot;
    };
    enum class RegisterResult { Ok, DuplicateId, EmptyProgram, BadOpCode, ParamMaskUnsupported };

    RegisterResult Register(uint32_t recipeId, const RecipeEntry& entry) {
        if (entries_.count(recipeId)) return RegisterResult::DuplicateId;
        if (entry.bytecode.empty())   return RegisterResult::EmptyProgram;
        for (const auto& in : entry.bytecode) {
            if (!Recipe::IsValidSdfOpCode(in.opCode)) return RegisterResult::BadOpCode;
            if (in.paramMask != 0)                    return RegisterResult::ParamMaskUnsupported; // dynamic params = P4
        }
        entries_.emplace(recipeId, entry);
        return RegisterResult::Ok;
    }
    const RecipeEntry* Get(uint32_t recipeId) const {
        auto it = entries_.find(recipeId);
        return it == entries_.end() ? nullptr : &it->second;
    }
    std::vector<uint32_t> Ids() const {
        std::vector<uint32_t> out; out.reserve(entries_.size());
        for (const auto& kv : entries_) out.push_back(kv.first); // std::map → ascending
        return out;
    }
    // Mutable access for the baker (I3) to stamp octreeSlot.
    RecipeEntry* GetMutable(uint32_t recipeId) {
        auto it = entries_.find(recipeId);
        return it == entries_.end() ? nullptr : &it->second;
    }
private:
    std::map<uint32_t, RecipeEntry> entries_;
};

} // namespace Vixen::SVO
```
