MECHANISM CHANGE
-----------------
CPU (BuildRenderGraph.cpp): probeUpdateNode's PARAM_DISPATCH_X changed from
the flat probeCount (512) to ceil(probeCount/amortizationFactor), reading
amortizationFactor via the new ResolveDdgiAmortizationFactor() (
ProbeGridConfigNode.h/.cpp) -- the SAME accessor MakeDefaultProbeGridConfig
uses for the GPU-side config upload, so the two values can never disagree
without duplicating the env-var-read logic.

Shader (ProbeUpdate.comp): probeIndex is now a stride-remap of
gl_WorkGroupID.x (`w*F + frameCounter%F`) instead of a direct 1:1 mapping.
Inc5 M1's early-out (`probeIndex%F != frameCounter%F -> return`) is REMOVED
as structurally dead code -- the sparse dispatch itself only ever produces
active-slot indices, so that condition could never fire for any workgroup
that actually runs. The pre-existing `probeIndex >= probeCount` bound-check
is KEPT, now serving the ceil()-driven over-dispatch guard for non-divisible
probeCount/F instead of its old purpose.
