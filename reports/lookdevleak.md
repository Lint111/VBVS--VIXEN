- **Full CPU 22-failure delta not established.** The fresh app-focused tree exposed only 29 CPU tests; all 29 passed after building their missing binaries. The complete base CPU set was not built or rerun, so no full-suite before/after delta is claimed.
- **F394 consumer contract is incomplete for VIXEN.** The combined kernel revision is now available and its generator tests are green, but its shared-path source also emits `PathDistance`. An owner decision is required: add the full VIXEN `PathInstance` storage/dispatch contract, or provide an approved canonical callable-selection input for consumers that only support glyph buckets.
