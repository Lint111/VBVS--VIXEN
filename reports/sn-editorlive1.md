## HOW AN AGENT ITERATES THE UI
Setup, once: build the editor once (`vixen_editor`), then start it with `VIXEN_UI_SOURCE_DIR=<repo>/VIXEN/libraries/RenderGraph/assets` (so the watched files are the source files; without it the staged copy next to the binary is read and edits to the source do nothing), `VIXEN_APPFLOW_DESCRIPTOR=<file>` (the channel descriptor), and, under Dozen, the queue's GPU environment. Never restart it for a UI or AppFlow-data change.
1. **Edit the file.** Panel structure and labels: `assets/ui/editor_*.rml`, `dock.rml`; look: `assets/ui/editor.rcss`, `dock.rcss`, `hud.rcss`; keys and element-trigger patterns: `VIXEN/libraries/AppFlow/assets/AppFlow.appflow` (a `keydefault <Id> <actionId> <keyId> <mods> <scope> <state>` row; key ids are the `key` rows of the same file). A plain write is enough: the editor polls every 15 ticks (about 0.3 to 0.7 s measured) and reloads on its own. To regenerate the `.appflow` from the schema (`codegen/appflow-schemas/AppFlowReference.cs`) without building C++: `YEROKET_ROOT=~/projects/Yeroket-Fantasy cmake --build <build>/wsl-debug --target appflow_regen` through the queue (it runs only the kernel CodegenTool `--appflow` and rewrites `AppFlow.g.h` + `AppFlow.appflow`; MEASURED: 3 s through the queue, both files regenerated byte-identical ("no change"), no C++ rebuild; `regen-1.log`).
2. **Force or confirm the reload** (optional, deterministic): `ui.reload {panel: "layers"}` (no `panel` = every document) returns `{ok, files:[{file, ok, error?:{line,column,message}}], frame}` per file. `appflow.reload` does the same for the `.appflow`. A broken file returns `ok:false` with `file:line` and the old document stays; the same text is on the status line and in `appflow.read` `diagnostic` (code `UiReload`); the next successful reload clears it.
3. **Wait for the frame that contains the change:** use the `ui.reload` request id as `actionId`: `appflow.await_frame {actionId}` or `appflow.readback {actionId, selection}`, or attach `readback: {selection: ...}` to `ui.reload` and get the pixels in the reply. For a watched (no verb) reload, subscribe to the `ui.reloaded` event (`appflow.subscribe`) or poll `appflow.readback {selection:{type:selector, selector:"<element id>"}}` for the element's bounds.
4. **Check:** `appflow.readback` with `fullFrame`, `screenRect` or `selector` (bounds + pixels + hash); `appflow.list` for the reloaded `selectors`/`chords`; `appflow.input` (key/text/pointer) to drive the real input path.
5. **Code-gated cases:** a new handler body, a new view field producer or a new action needs a build (design note section 2). A `.appflow` whose shape hash no longer matches the compiled one is rejected with "rebuild required", the last good state stays.

## FRAMEWORK GAPS
1. **`AppFlowRuntime::Load` wiped the running state on every `.appflow` reload** (fresh fsm, fresh undo stack, `handlers_.clear()`): MEASURED undo depth 1 -> 0 after editing a key default (run1). Fixed here with `Reload`; `Load` itself is unchanged.
2. `appflow.list` reported the compiled-in selectors and chords after a reload (fixed here for selectors and chords; `actions`, `transitions`, `dataTargets` are still the compiled-in tables, correct only while the shape gate holds).
3. An action declared in data with no registered handler returns `RejectedByState` with no diagnostic (`AppFlowRuntime.cpp:163`): silent non-emission (R796). Design note 2.iii.
4. RmlUi reports no column; `column` is always 0. Two error lines per XML error (terse + descriptive) are merged by ordering, not de-duplicated.
5. A reload of a document whose focused field had uncommitted text drops that text (only focus and caret are restored); the forwarder may commit on the blur of the unloaded document (not measured).
6. Images an `.rcss` references are not watched; the HUD `.viewblob` has its own reload (`PollHudHotReload`) and was left alone.
7. The shape hash in the `.appflow` is compared, not recomputed (design note section 1); a hand-edited `action` row passes the gate.
8. `appflow_regen` also rewrites `AppFlow.g.h`; a key-default change that does not change the shape needs no C++ build, but the regen target cost 3 s (MEASURED).
