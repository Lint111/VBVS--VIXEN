## B6: what changed

`traceUberRecipeBody` (`VIXEN/shaders/SdfRecipes.glsl`) is the hand-written sphere-march every
recipe ray uses; only the field function it calls (`evalRecipeField`) is generated by the kernel's
recipe GPU service. The shadow wave (`ShadowVisibilityWave.comp`) and `TraceWorldShadowImpl`
(`TraceWorld.glsl`) are hand-written passes too, so B6 is a hand edit there and **the kernel is
unchanged** (no generated pass is touched; R619.1/R665.3 apply to the field, which does not change).

- `traceUberRecipeBodyImpl(..., bool occlusionOnly, ...)` holds the march. With `occlusionOnly`
  the step sequence, the refinement bracket and `hitT` are the same instructions as before; only the
  six-evaluation central-difference gradient and the material evaluation at the certified hit are
  skipped. Two forms: `traceUberRecipeBody` (nearest hit, camera and probe rays) and
  `traceUberRecipeBodyAnyHit` (visibility rays).
- Callers: `TraceWorldShadowImpl` (through `traceRecipeChunks`, which takes the flag) and the
  ray-query any-hit twin `traverseRayQueryWorldAnyHit` (`RayQueryTraversal.glsl`). Both read only
  hit and distance. The shadow loop no longer transforms the normal it never read.
- The global `g_recipeProvenStepOnly` is deleted: it was set to `true` only around exactly these
  two any-hit calls, so the parameter carries the same rule for the relaxed-step boost.
- `g_lastRecipeMaterialId` is read only after nearest-hit traces (`TraceWorld.glsl`,
  `RayQueryTraversal.glsl` primary path), never after a shadow trace (git grep).
- CPU parity: `TraceWorldShadowMirror` (`test_traceworld_mirror.cpp`) models occluders abstractly
  and has no recipe march or gradient, so there is no CPU face to change. The CPU march oracles in
  the bucketed-dispatch tests mirror the primary march, which is unchanged.
- Why exact: the occlusion answer is `pHit && pT in [max(tmin, 1e-3), tmax]`, and `pHit`/`pT`
  come from the unchanged stepping; the removed values were never read. The primary path passes
  `false`, which leaves the same arithmetic as before.
